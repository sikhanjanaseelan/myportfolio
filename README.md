# MyPortfolio

MyPortfolio is a reusable custom WordPress portfolio system built with:

- A custom WordPress theme
- A custom core plugin
- Reusable template components
- Modular CSS
- Dynamic portfolio content
- Responsive and accessible layouts

## Main Components

### Theme

`wp-content/themes/myportfolio`

Controls the frontend design, templates, layout, components and responsive behaviour.

### Core Plugin

`wp-content/plugins/myportfolio-core`

Controls projects, skills, experience, services, testimonials, clients, reusable sections and site settings.
